💳 PG (Payment Gateway) vs VAN 사 결제 승인 구조 & 실무 예시

온라인 쇼핑몰 결제와 오프라인 매장 결제의 차이점 및 가맹점-PG-VAN-카드사 간의 정산과 망 중계 흐름

🌐 1. 온라인 쇼핑몰 카드 결제 흐름 (예: 무신사에서 나이키 운동화 구매)

개별 스타트업/쇼핑몰이 수많은 카드사(신한, 현대, 국민 등)와 일일이 가맹 계약을 맺기 어렵기 때문에, PG사(토스페이먼츠, KG이니시스)가 대표 가맹점 역할을 대행하고 결제 UI 창을 제공합니다.

1. 구매자
무신사 앱 결제 클릭
➔
2. 온라인 쇼핑몰
무신사 백엔드 서버
➔
3. PG 사
토스페이먼츠 / KG이니시스
(결제창 호출 & 대행)
➔
4. VAN 사
NICE / KICC
(보안 전용망 중계)
➔
5. 카드사
신한/현대카드
(한도 검증 & 승인)

☕ 2. 오프라인 매장 카드 결제 흐름 (예: 스타벅스에서 카드 긁기)

오프라인 매장에는 결제 웹페이지가 필요 없으므로 PG사가 개입하지 않고, POS 단말기가 VAN사의 물리 통신망을 통해 직접 카드사로 승인 요청을 보냅니다.

1. 손님
실물 카드 IC칩 삽입
➔
2. 오프라인 매장
스타벅스 POS 계산대
➔
3. VAN 사 단말기
KICC / KIS정보통신
(전용선 데이터 전송)
➔
4. 카드사
국민/삼성카드
(승인 후 영수증 출력)

💡 3. PG vs VAN 핵심 차이 완벽 정리

PG (Payment Gateway)

  • 주요 역할: 온라인 쇼핑몰을 위한 웹 결제창 UI 제공, 통합 정산(수수료 정산 후 입금), 카드사별 가맹 계약 대행.
  • 수수료: 약 2.0% ~ 3.3% (결제 대행 수수료 포함).
  • 대표 기업: 토스페이먼츠, NHN KCP, KG이니시스, 나이스페이.

VAN (Value Added Network)

  • 주요 역할: 카드사와 가맹점(또는 PG사) 사이의 물리적인 '보안 통신 전용망'을 깔아주고 데이터 승인 트래픽을 안전하게 중계.
  • 수수료: 건당 수십 원 단위 중계 수수료 (카드사가 VAN사에 지급).
  • 대표 기업: NICE정보통신, KICC(한국정보통신), KSNET, KIS정보통신.
