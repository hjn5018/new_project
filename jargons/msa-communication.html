🌐 1. [기초 이해] HTTP/1.1 vs HTTP/2 핵심 차이점

REST API는 주로 HTTP/1.1 위에서 동작하고, gRPC는 HTTP/2를 기반으로 동작합니다. 두 프로토콜의 구조적 차이를 알면 왜 gRPC가 수배 빠른지 바로 이해할 수 있습니다.

비교 항목 HTTP/1.1 (REST API 기반) HTTP/2 (gRPC 기반)
데이터 전송 포맷 텍스트(Plain Text) 기반 (인간이 읽기 편한 ASCII 문자열) 바이너리 프레임(Binary Frame) 기반 (0과 1로 압축된 초소형 패킷)
동시 요청 처리 방식 순차 처리 (1 커넥션 = 1 요청)
앞선 요청이 느리면 뒤 요청이 대기하는 HOL(Head-of-Line) 블로킹 발생 		멀티플렉싱 (Multiplexing)
단 1개의 TCP 연결 속에서 수백 개의 요청/응답 스트림을 동시에 병렬 전송
헤더 처리 매 요청마다 수 킬로바이트(KB) 헤더를 압축 없이 중복 전송 HPACK 압축을 사용하여 중복 헤더는 인덱스 번호만 전송
