🔄 Kafka CDC (Change Data Capture) 아키텍처

DB 트랜잭션 로그(Binlog/WAL)를 실시간 감지하여 애플리케이션 수정 없이 타겟 시스템에 동기화하는 기법

📊 Debezium + Kafka Connect CDC 실시간 동기화 흐름

Source DB
MySQL (binlog)
PostgreSQL (WAL)
➔
Debezium Connector
변경 로그 테일링
➔
Kafka Topic
dbserver.users
➔
Target Sink
Elasticsearch / Redis / Data Lake

💡 백엔드 실무 적용 주요 이점

  • Zero Code Mutation: 애플리케이션 백엔드 소스 코드를 단 한 줄도 수정하지 않고 DB 레벨의 CUD(Create, Update, Delete) 이벤트를 감지.
  • 검색엔진 / 캐시 실시간 동기화: RDBMS에 데이터가 INSERT/UPDATE되면 0.1초 내로 Elasticsearch 인덱스 및 Redis 캐시가 자동 갱신됨.
  • 이중 작성(Dual Write) 문제 해결: DB 저장 성공 후 Elasticsearch 저장에 실패하는 분산 트랜잭션 불일치 문제 완벽 해소.
