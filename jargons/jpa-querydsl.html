⚔️ JPA vs QueryDSL 공통점과 차이점 분석

자바 ORM 표준(JPA/JPQL)의 단점을 보완하여 타입-세이프(Type-Safe) 컴파일 타임 동적 쿼리를 가능하게 하는 관계

💡 JPA(JPQL) vs QueryDSL 나란히 코드 비교

JPA / JPQL (문자열 쿼리)

// ⚠️ 오타가 있어도 컴파일 통과 (런타임 에러)
String jpql = "select m from Member m " +
  "where m.username = :name and m.age > :age";

List<Member> result = em.createQuery(jpql, Member.class)
  .setParameter("name", "홍길동")
  .setParameter("age", 20)
  .getResultList();

QueryDSL (타입-세이프 자바 코드)

// ✅ 컴파일 타임 문법 검사 & 자동완성 지원
QMember m = QMember.member;

List<Member> result = queryFactory
  .selectFrom(m)
  .where(
    m.username.eq("홍길동"),
    m.age.gt(20)
  )
  .fetch();

📊 핵심 공통점 및 차이점 비교표

항목 JPA (Spring Data JPA) QueryDSL
관계 QueryDSL은 JPA 위에서 동작하는 빌더 프레임워크 (대체재가 아닌 보완재)
동적 쿼리 문자열 더하기로 조합이 복잡함 BooleanBuilder 및 BooleanExpression 메서드 재사용 가능
권장 사용처 단순 CRUD (`findById`, `save`) 복잡한 조건 검색, 다중 JOIN, 통계 쿼리
