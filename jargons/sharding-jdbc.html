🗄️ Sharding-JDBC 데이터 분산 샤딩 실습 & 라우터

애플리케이션 레이어에서 단일 쿼리를 여러 물리적 DB 디비전(ds_0, ds_1) 및 테이블(t_order_0, t_order_1)로 분산 라우팅하는 기술

🕹️ Sharding Key 기반 라우터 시뮬레이터

🎯 라우팅 결과: ds_1.t_order_1 테이블로 직접 타겟팅 쿼리 전송! (Scatter-Gather 비용 무)

📘 Spring Boot application.yml 샤딩 설정 예시

spring:
  shardingsphere:
    datasource:
      names: ds_0, ds_1
    rules:
      sharding:
        tables:
          t_order:
            actual-data-nodes: ds_$->{0..1}.t_order_$->{0..1}
            table-strategy:
              standard:
                sharding-column: user_id
                sharding-algorithm-name: inline-order-algorithm
        sharding-algorithms:
          inline-order-algorithm:
            type: INLINE
            props:
              algorithm-expression: t_order_$->{user_id % 2}
