🗄️ Sharding-JDBC 데이터 분산 샤딩 & 시각적 라우터 다이어그램

애플리케이션 레이어에서 단일 쿼리를 여러 물리적 DB 디비전(ds_0, ds_1) 및 테이블로 분산 라우팅하는 기술

📊 1. Sharding-JDBC 쿼리 라우팅 시각 아키텍처

1. Spring App
SELECT * FROM t_order
WHERE user_id = 105
➔
2. Sharding-JDBC
샤딩 알고리즘 연산
105 % 2 = 1 (홀수)
➔
3. 물리 DB 타겟팅
ds_1.t_order_1 로만
단일 전송 (분산 부하 0)

🗄️ Database Division 0 (ds_0)

샤딩 키 조건: user_id % 2 == 0 (짝수 유저)
• 테이블: t_order_0
• 데이터: user_id = 100, 102, 104, 106...

🗄️ Database Division 1 (ds_1)

샤딩 키 조건: user_id % 2 == 1 (홀수 유저)
• 테이블: t_order_1
• 데이터: user_id = 101, 103, 105, 107...

🕹️ 2. Sharding Key 기반 실시간 라우터 시뮬레이터

🎯 라우팅 결과: ds_1.t_order_1 테이블로 직접 타겟팅 쿼리 전송! (단일 샤드 조회)

📘 3. Spring Boot application.yml 샤딩 설정 예시

spring:
  shardingsphere:
    datasource:
      names: ds_0, ds_1
    rules:
      sharding:
        tables:
          t_order:
            actual-data-nodes: ds_$->{0..1}.t_order_$->{0..1}
            table-strategy:
              standard:
                sharding-column: user_id
                sharding-algorithm-name: inline-order-algorithm
        sharding-algorithms:
          inline-order-algorithm:
            type: INLINE
            props:
              algorithm-expression: t_order_$->{user_id % 2}
