🔌 WebSocket vs STOMP 프레임 구조 비교

순수 전송 계층 프로토콜(WebSocket)과 그 위에서 서브스크립션 메시지 규격을 정의하는 상위 프로토콜(STOMP)

💡 STOMP 메세지 프레임 구조 예시

순수 WebSocket은 텍스트/바이너리 데이터만 전달하지만, STOMP는 HTTP처럼 COMMAND, Headers, Body 구조를 가집니다.

SEND
destination:/topic/chat/room101
content-type:application/json

{"sender":"홍길동", "message":"안녕하세요! 선착순 티켓 수량 남았나요?"}^@

📊 핵심 차이점 분석

  • WebSocket: TCP 3-way handshake 후 HTTP 핸드셰이크를 통해 양방향 파이프(Pipe)를 연결하는 Transport 프로토콜. 데이터의 형태(JSON, String 등)를 직접 파싱해야 함.
  • STOMP (Simple Text Oriented Messaging Protocol): WebSocket 통신 위에서 동작하며, SUBSCRIBE, SEND 명령어로 Pub/Sub 브로커(Spring MessageBroker, Redis)와 쉽게 연동 가능.
