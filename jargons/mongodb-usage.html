실무 사례 3

📊 MongoDB Aggregation Pipeline (집계 파이프라인)

SQL의 WHERE ➔ GROUP BY ➔ ORDER BY 처럼, 파이프라인 단계($match ➔ $group ➔ $sort)를 거치며 대용량 주문 데이터에서 VIP 유저별 총 결제 금액을 연산합니다. 

db.orders.aggregate([
  // 1단계: 결제 완료된 건만 필터링 (SQL WHERE status = 'PAID')
  { $match: { status: "PAID" } },
  
  // 2단계: 유저별로 그룹핑하여 총 결제액 및 주문 건수 합산 (SQL GROUP BY userId)
  { 
    $group: { 
      _id: "$userId", 
      totalSpent: { $sum: "$amount" }, 
      orderCount: { $sum: 1 } 
    } 
  },
  
  // 3단계: 총 결제액 기준 내림차순 정렬 (SQL ORDER BY totalSpent DESC)
  { $sort: { totalSpent: -1 } },
  
  // 4단계: 상위 10명 추출 (SQL LIMIT 10)
  { $limit: 10 }
]);
