2. MongoDB Aggregation Pipeline vs SQL JOIN

$match ➔ $group 파이프라인 연산으로 주문 총액 통계를 고속 계산합니다.

db.orders.aggregate([
  { $match: { status: "PAID" } },
  { $group: { _id: "$userId", totalSpent: { $sum: "$amount" }, totalOrders: { $sum: 1 } } },
  { $sort: { totalSpent: -1 } }
]);
