🍃 NoSQL 데이터베이스 4대 데이터 모델 심층 비교

엄격한 관계형 스키마(RDBMS)를 탈피하여 높은 가용성과 수평 확장을 제공하는 NoSQL의 종류별 특징

📊 NoSQL 4대 구조별 특징 매트릭스

Document Store

MongoDB / Couchbase

JSON/BSON 형태의 가변 구조 문서를 저장. 중첩 객체 및 배열 지원이 뛰어나며 가장 넓은 범용성 보유.

Key-Value Store

Redis / DynamoDB

Unique Key와 Value를 1:1 매핑. 초고속 읽기/쓰기 성능을 제공하며 인메모리 캐싱 및 대기열에 특화.

Wide-Column

Cassandra / HBase

행마다 서로 다른 컬럼 집합을 저장. 대용량 분산 쓰기 성능이 매우 뛰어나 시계열 로그 적재에 활용.

Graph Database

Neo4j / Amazon Neptune

Node와 Edge(관계) 형태로 데이터를 저장. SNS 친구 관계망, 추천 알고리즘 복잡한 릴레이션 탐색 최적화.
